# تطبيق Android: إرسال الكروت تلقائيًا عند وصول رسالة إيداع

هذه نسخة مصدرية Native Android بلغة Java لتطبيق يراقب رسائل SMS الواردة من:

- Jawali / جوالي
- Jaib / جيب

ثم يستخرج المبلغ ورقم العميل، ويرسل كرتًا من نفس الفئة فقط.

## القاعدة الأساسية

- 100 ريال → كرت فئة 100 فقط
- 200 ريال → كرت فئة 200 فقط
- 250 ريال → كرت فئة 250 فقط
- لا يوجد دمج أو استبدال للفئات.

## صيغ الرسائل المدعومة حاليًا

### جوالي

```text
استلمت مبلغ 100 YER من 774583505 رصيدك هو 2478.34
```

### جيب

```text
اضيف 250ر.ي تحويل مشترك رص:15598.76ر.ي من أسامه عبدالحق-738119852
```

## الوظائف

- مراقبة رسائل SMS الواردة.
- التعامل فقط مع Jawali/Jaib/جوالي/جيب.
- استخراج المبلغ ورقم العميل.
- سحب أول كرت متاح من نفس الفئة.
- إرسال الكرت تلقائيًا عبر SMS.
- منع تكرار نفس الرسالة.
- تسجيل العمليات.
- استيراد الكروت من ملف TXT.
- إضافة الكروت يدويًا، كل سطر كرت.
- تشغيل/إيقاف الإرسال التلقائي.

## صيغة ملف TXT

كل سطر = كرت واحد:

```text
1234567890
9876543210
5555666677
1111222233
```

قبل الاستيراد اختر الفئة، مثل 100، ثم اختر الملف.

## الصلاحيات المطلوبة

```text
RECEIVE_SMS
READ_SMS
SEND_SMS
```

عند أول تشغيل امنح التطبيق الصلاحيات.

## طريقة البناء

افتح المشروع في Android Studio ثم:

1. انتظر مزامنة Gradle.
2. من القائمة اختر Build.
3. اختر Build APK.
4. ثبّت ملف APK على الهاتف.

## ملاحظات مهمة

- هذا التطبيق مخصص للاستخدام الشخصي/الخاص على جهازك.
- إذا كان الهاتف Dual SIM، إرسال SMS سيكون من شريحة الرسائل الافتراضية في النظام.
- يجب تجربة النظام أولًا بمبلغ صغير وكروت تجريبية.
- إذا غيرت صيغة رسائل Jawali أو Jaib، يلزم تعديل ملف PaymentParser.java.
