# تطبيق Android: إرسال الكروت تلقائيًا عند وصول رسالة إيداع - V2

هذه النسخة تضيف:

- دعم ONE Cash / ون كاش.
- قائمة الأسماء الموثوقة.
- مطابقة الاسم الثلاثي في رسائل ONE Cash.
- الفئات الافتراضية:
  50، 100، 150، 200، 250، 300، 500.
- إمكانية إضافة فئات أخرى يدويًا.

## القاعدة الأساسية

- 50 ريال → كرت فئة 50 فقط.
- 100 ريال → كرت فئة 100 فقط.
- 150 ريال → كرت فئة 150 فقط.
- 200 ريال → كرت فئة 200 فقط.
- 250 ريال → كرت فئة 250 فقط.
- 300 ريال → كرت فئة 300 فقط.
- 500 ريال → كرت فئة 500 فقط.
- لا يوجد دمج أو استبدال للفئات.

## صيغ الرسائل المدعومة

### جوالي

```text
استلمت مبلغ 100 YER من 774583505 رصيدك هو 2478.34
```

### جيب

```text
اضيف 250ر.ي تحويل مشترك رص:15598.76ر.ي من أسامه عبدالحق-738119852
```

### ONE Cash

```text
استلمت 200.00
من غالب احمد علي ه
رصيدك4,809.05 ر.ي
```

في ONE Cash لا يوجد رقم في الرسالة، لذلك يجب حفظ الاسم ورقم الهاتف مسبقًا في:

```text
الإعدادات → الأسماء الموثوقة لوَن كاش
```

## مطابقة الاسم الثلاثي

إذا كان الاسم في الرسالة:

```text
غالب احمد علي ه
```

فالتطبيق يطابق أول ثلاثة أسماء فقط:

```text
غالب احمد علي
```

إذا وجد الاسم الثلاثي في الأسماء الموثوقة، يرسل الكرت إلى الرقم المحفوظ.  
إذا لم يجده، يسجل العملية معلقة ولا يرسل الكرت.

## بناء APK عبر GitHub Actions

هذا المشروع يحتوي ملف workflow في:

```text
.github/workflows/build-apk.yml
```

بعد رفع الملفات إلى GitHub:

1. افتح Actions.
2. اختر Build Android APK.
3. شغل Run workflow أو انتظر التشغيل التلقائي بعد الرفع.
4. حمّل Artifact باسم:
   auto-sms-cards-debug-apk
5. فك الضغط وستجد:
   app-debug.apk
